# Roadmap

## Included
- Theme block: options, editor, live preview, logo upload, confirmation, edit/skip/remove
- Admin: dashboard, products (search, pagination, enable/disable), product configuration,
  icon/font/colour/placement libraries, pricing, uploads, settings, add-on product creation
- Cart Transform pricing with currency conversion
- Order statistics (orders/create), privacy webhooks, uninstall cleanup
- Unit + browser tests, static checks
